Features

刷课、答题、搜题，一站式

把重复的点击交给脚本，把思考的时间留给自己。

  • 全自动刷课

    视频自动播放、章节与任务点智能切换，PPT / 文档 / 阅读任务自动完成，全程无需值守。

  • 四题型 AI 答题

    单选、多选、判断、填空全面覆盖，全新答案匹配算法 + 多线程搜题，答题进度实时可视。

  • 调用 AI 大模型

    兼容 OpenAI 格式接口，DeepSeek、Kimi、智谱、硅基流动、百炼云随心接入。

  • 题库 × 划词搜题

    自定义题库配置，兼容 TikuAdapter 第三方题库，划词即搜，题库缓存秒级响应。

  • 倍速与音量

    各平台视频倍速自由调节，支持屏蔽倍速限制，音量随课程记忆。

  • 隐形反检测

    在页面加载的最初一刻就悄悄介入，全程把状态伪装成正常观看的样子，低调运行，不留痕迹。

  • 悬浮窗面板

    操作面板随页面悬浮，状态一目了然；移动端同样适配，手机也能用。

  • 贴心小细节

    解除页面复制限制、禁止骚扰弹窗、系统通知提醒、自动检测更新。

FAQ

常见问题

支持哪些网课平台？

目前支持超星学习通、知到·智慧树、职教云、智慧职教（icve）、雨课堂、中国大学MOOC、U校园七大平台，覆盖视频学习、阅读任务、作业与考试等场景。

AI 答题如何配置？

插件兼容 OpenAI 格式接口，支持 DeepSeek、月之暗面 Kimi、智谱、硅基流动、百炼云等主流模型，填入 API Key 即可使用；同时也支持自定义题库与 TikuAdapter 第三方题库。

手机上能用吗？

可以。悬浮操作面板已全面适配移动端屏幕，配合支持扩展的移动浏览器即可使用。

我的数据安全吗？

桌面版所有配置均经 AES-256-GCM 加密存储，加密密钥保存在操作系统密钥链中；所有数据留在本机，不经过任何第三方服务器。

桌面版和浏览器插件是什么关系？

插件是核心功能本体；桌面版是多开管理与无人值守的运行环境，内置了同款插件并自动安装、自动升级。只用浏览器装插件即可，需要多账号批量时再上桌面版。

它是开源的吗？

是。鸿鹄易学由鸿鹄科技开发，以 MIT 协议开源，完整代码托管在 GitCode 与 GitHub，欢迎 Star 与贡献。
